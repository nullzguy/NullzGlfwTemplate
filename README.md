This is a little GLFW + OpenGL + ImGUI template i made.
This can be used for experiments, projects, and whatever comes to your mind.
build.bash efficiently and simply builds & runs your project.
Make sure to change the project name in CMakeLists.txt, and in build.bash if you want to.
This template is supposed to work on unix systems, the requirements are GLFW, OpenGL, GLM.
